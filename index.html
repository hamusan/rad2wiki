COLLECTOR’S FIELD GUIDE · 01

Buddycards集めるほど、冒険が広がる。

探索で見つけたパックを開け、カードを集める。コレクションを収納・展示しながら、メダルや装備の強化を目指すMODです。

このページの対象

Minecraft Java Edition 1.16.5 / Buddycards 2.5.3。公式の1.16.5ブランチを基準にしています。新しい版の仕様やMODパック独自の変更とは異なる場合があります。

最初のパックから始めよう

  1. 探索してパックを見つける

    村・廃坑・ダンジョンなどのチェストで、Base Setのパックを探します。

  2. 手に持って開封する

    基本セットのパックには通常カード3枚とキラカード1枚が入っています。

  3. 重複カードで収納を作る

    同じセットのカード3枚と革1枚でBinderを作成。初めて入手したカードは残しておきましょう。

導入するもの

ForgeのMinecraft 1.16.5環境に、対応するBuddycardsを導入します。ここで解説するファイルは Buddycards-1.16.5-2.5.3.jar です。配布ページではゲームバージョンを確認してください。

Curios API

メダルや指輪を装備して効果を使うための連携MODです。1.16.5版のBuddycards本体では必須依存として宣言されていませんが、装備スロットを使う遊び方には導入します。

Patchouli / JEI

Patchouliを導入すると、本1冊＋カード1枚でゲーム内ガイドを作れます。JEIはレシピ確認に便利です。MODパックでは変更済みのレシピをJEIで確認してください。

02 · PACKS & SETS

パックはどこで手に入る？

まずは3つの基本セットを集めましょう。各セットは27絵柄で、それぞれに通常版とキラ版（Foil / Shiny）があります。基本パック1個から出るのは通常3枚＋キラ1枚です。

セット主な入手先補足
Base Setオーバーワールド廃坑、村、ダンジョン、難破船、埋もれた宝、砂漠の寺院などのチェスト子どものゾンビ・村人・村人ゾンビからも低確率でドロップ。
Nether Setネザーネザー要塞、砦の遺跡、荒廃したポータルなどのチェスト。ピグリンとの物々交換子どものピグリン・ゾンビピグリンからも低確率でドロップ。
End Setジ・エンドエンダードラゴン討伐、エンドシティのチェストシュルカーからも低確率でドロップ。

出典：ゲーム内ガイド Base / Nether / End

レア度とカード番号

レア度はカードの四隅で判別できます。キラかどうか、鑑定の等級が何か、とは別の分類です。

レア度27枚セットの番号四隅の特徴1枚ごとの抽選率
Common1〜12色付きの角なし50%
Uncommon13〜21黄色2か所30%
Rare22〜25青色4か所15%
Epic26〜27黄色2か所＋紫色2か所5%

数値はレア度全体の確率です。特定のカード1種類の排出率ではありません。通常枠とキラ枠で同じレア度抽選を行います。

Mystery Pack

複数のセットからカードを引ける特別なパックで、9枚中2枚がキラです。連携MODが未導入のセットを抽選対象に含めるかは設定で変わります。基本パックとは分けて考えましょう。

出典：パックの抽選処理 / Mystery Pack

03 · STORAGE

集めたカードをしまう・飾る

アイテム用途・容量使い分け
Buddycard Binderバインダーカード用54スロット。各スロットにスタック可能持ち運びの基本。同セットのカード3枚＋革1枚で作成。
Ender Binderエンダーバインダープレイヤーごとの共有収納。通常バインダー相当の容量カード3枚＋エンダーアイ1個。紛失しても作り直せば中身にアクセス可能。

収納のエンチャント

Extra Page はバインダーの容量を増やします。Buddy Binding は死亡時に対象アイテムを保持できるエンチャントで、最大レベルはIIIです。Buddysteel Key では展示棚やスタンドなどを施錠できます。

04 · COLLECTION REWARDS

セットを完成させてメダルを手に入れる

セット完成の進捗報酬としてメダルを獲得できます。Curiosの対応スロットに装備すると、セットごとの効果を得られます。持ち物に入れているだけでは装備効果は発動しません。

2.5.3では、通常・キラ両方をそろえる必要はありません

基本セットの進捗データは27種類のカードIDを判定し、キラや鑑定の状態は指定していません。各絵柄を通常版またはキラ版のどちらかで取得すれば条件を満たします。ゲーム内ガイドの「通常とキラをすべて」という記載より、実際の進捗データを優先しています。

メダル通常の効果Buddy Boost IBuddy Boost II
Base移動速度上昇 I移動速度上昇 II移動速度上昇 III
Nether火炎耐性炎上中に移動速度上昇 Iを追加炎上中に移動速度上昇 I・攻撃力上昇 Iを追加
End耐性 I浮遊を定期的に解除耐性 II＋浮遊を定期的に解除

セット完成の判定はインベントリの変化で記録されます。収納の中にあるカードを集めても進捗が埋まらないときは、一度プレイヤーのインベントリへ移してください。

05 · BUDDYSTEEL

コレクションで育つ装備

Buddysteelは、カードを素材にした金属です。剣・道具・防具などを作れます。余ったカードを使い、収集の進み具合に応じて装備を強くしていきます。

基本の作り方 · 不定形レシピ

鉄ブロック ×1 ＋ ラピスラズリブロック ×1 ＋ カード ×3

→ Buddysteel Blend ×1 → 精錬 → Buddysteel Ingot ×1

通常のかまどでは精錬に1,600 tick（20 TPSなら80秒）かかります。少量の鉄インゴットやラピスではなく、ブロックを使うレシピです。MODパックやCreate連携には別レシピもあります。

完成率の仕組み

2.5.3の装備が参照するのは、読み込まれているカードのうち、一度でも拾ったことがある種類の割合です。枚数の合計でも、バインダーに入っている枚数でもありません。同じ絵柄のキラや鑑定違いを増やしても、別のカードIDとしては数えません。

  1. 未収集の種類を入手します。チェストなどから移しただけで反映しない場合、安全な場所でカードを落として拾い直します。
  2. 強化したいBuddysteel装備を手に持ち、右クリックして記録を更新します。
  3. ツールチップの完成率を確認します。連携MODで対象カードの種類数が増えると、分母も変わります。

Perfect Buddysteel

LuminisとZylexを使う上位素材です。Perfect Buddysteel Ingotと通常のBuddysteel装備を鍛冶台で組み合わせ、上位装備に更新します。収集率で成長する性質は引き継がれます。

出典：基本レシピ / 精錬 / 完成率の計算 / 更新操作 / 上位装備

06 · GRADING

鑑定は、さらに集めたい人のために

未鑑定のカードをメインハンド、Grading Sleeveをオフハンドに持って使用すると、スリーブを1個消費してカード1枚を鑑定します。等級はD・C・B・A・Sの5段階。2.5.3では鑑定済みのカードを同じ操作で再鑑定できません。

等級DCBAS
補正なしの確率39.8%32%18%10%0.2%

実装の1〜500の乱数と境界条件から算出。Grading Luckなどの補正がある場合は、この表の確率とは異なります。鑑定の等級は、装備の完成率を直接増やすものではありません。

スリーブのレシピ

作業台の上段を「金インゴット・板ガラス・鉄インゴット」、中段を「鉄インゴット・板ガラス・金インゴット」と並べると、Grading Sleeveが2個できます。

出典：鑑定処理・確率 / スリーブのレシピ

07 · LATE GAME

LuminisとEnderling

MINING

Luminis / Deep Luminis

地下の低い場所で見つかるLuminis鉱石から結晶を集め、精錬して素材にします。光る建材やPerfect Buddysteelの材料になります。

Deep Luminisは希少な派生素材。鉱石からの入手に加え、2.5.3では通常のLuminisブロックを爆破して得る方法もあります。入手しやすさは専用装備などで変わります。

TRADING

Enderling / Zylex

Enderlingはエンダーマンとともにまれに現れる友好的な存在です。カードと、独自の素材・通貨であるZylexを取引します。

取引を使い切ったらZylex Tokenで更新できます。同じ個体と取引を重ねると、Zylex系の特別な装備を扱うようになります。Zylexも上位Buddysteelの材料です。

出典：Luminis / Deep Luminis / Enderling / Token / 特別な取引

08 · MOD INTEGRATIONS

ほかのMODと組み合わせる

1.16.5版には、対応MODを導入すると遊べる連携セットがあります。後年の別MOD「Buddycards Expansions」の案内と混同しないようにしてください。

連携セット絵柄数 / パック集め方メダルの基本効果
Oh The Biomes You'll Go（BYG）27種類 / 4枚各ディメンションのBYG素材などを使ってパックを作成。跳躍力上昇 I
Create27種類 / 4枚粉砕・混合・順序付き組立でパックを製造。下記参照。採掘速度上昇 I
Aquaculture18種類 / 3枚Buddycard Hookを付けた釣り竿やBuddysteel Fishing Rodで釣る。水中呼吸
Farmer’s Delight18種類 / 3枚＋グミ作物からBuddybeansなどを集め、カード片と料理してパックにする。Nourished I

18枚セットもパックにはキラ1枚が含まれます。番号はCommonが1〜7、Uncommonが8〜13、Rareが14〜16、Epicが17〜18です。

Create連携：2.5.3のパック製造

  1. カードやパックを粉砕し、Shredded Buddycardを用意します。
  2. カード片2個と水250 mBを混合して、Recycled Buddycardを作ります。
  3. Luminis Panelを開始素材にして、Recycled Buddycardをデプロイヤーで取り付け、水125 mBを注ぐ工程を4周行います。
  4. Create Setのパックが完成します。組立1個分に使う再生カードは4個、注水は合計500 mBです。
古いガイドの混合レシピに注意

同梱ガイドには「カード片・ナゲット・真鍮板を加熱混合」と書かれていますが、2.5.3のレシピファイルは上記の順序付き組立です。導入環境のJEIに表示されるレシピを優先してください。

09 · TROUBLESHOOTING

よくある疑問

メダルは取れたのに、装備の完成率が低いのはなぜ？

別々の判定を使っています。メダルはインベントリに入った種類、装備は拾った統計を参照します。安全な場所でカードを拾い直してから、装備を手に持って右クリックしてください。連携セットが完成率の対象になっている場合もあります。

キラカードやSランクは、攻略に必須？

2.5.3の基本セットのメダル条件には、キラや鑑定ランクの指定はありません。まずは各絵柄を集め、キラや鑑定は追加の収集目標にすると進めやすくなります。

同じカードが余ったらどうする？

バインダーやBuddysteelの素材に使えます。CreateやFarmer’s Delightがあれば、カード片への加工にも使えます。収集用の1枚を確保してから素材にするのがおすすめです。

メダルを持っているのに効果が出ない

Curios APIが導入されているか、対応する装備スロットにメダルを入れているかを確認してください。通常のインベントリに置くだけでは効果を使えません。

手元のレシピがこのページと違う
