RAD2で拾ったカードを、クエスト・メダル・装備強化につなげるためのガイド。通常版のBuddycardsと異なる収集環境や装備条件を、RAD2 1.17の配布データに合わせてまとめています。

1.17はMODパックのバージョンです。Minecraft本体は1.16.5、収録Buddycardsは2.5.3、Forgeは36.2.39。RAD2 1.17の公式配布ZIPを基準にしています。※150種類は6セット144絵柄＋グミ6種類を、収録MODとカード登録処理から算出した値です。

RAD2で最初にすること

  1. Card Collector章を開く

    FTB QuestsのCard Collector章を確認。最初のクエストはパックとBuddycardsガイド本を対象にしています。探索でパックを確保しましょう。

  2. クエスト確認後に開封する

    必要なパックの所持判定を済ませてから開封します。基本パックは通常3枚＋キラ1枚。初めての絵柄は自分のインベントリへ入れます。

  3. 重複カードで収納を作る

    同じセットのカード3枚と革1枚でBinderを作成。初めて入手したカードは残しておきましょう。

RAD2には必要なMODが収録済み

RAD2 1.17を導入している場合、Buddycards・Curios・Patchouli・JEIを別途追加する必要はありません。Buddycardsは Buddycards-1.16.5-2.5.3.jar が指定されています。単体MODを最新の別バージョンへ入れ替えず、RAD2の構成で遊んでください。

Curios API

RAD2に収録されています。メダルはCuriosの対応スロットへ装備します。通常インベントリやバックパックに入れるだけでは装備効果を得られません。

Patchouli / JEI

初期配布のAkashic TomeにはBuddycardsガイドが登録されています。必要なら本1冊＋カード1枚でも作れます。RAD2でのレシピはJEIを参照し、一般的なBuddycardsの動画と違う場合はRAD2側を優先してください。

出典：対象バージョン・依存関係 / Curios連携 / ガイド本レシピ

RAD2 · QUESTS & COINS

Card Collectorとコイン交換

Card Collector章の進め方

  1. パックとガイド本をそろえて導入クエストを確認。報酬はBase Setのパックです。
  2. 各セットのパックやバインダー、メダルを追い、分岐の前提クエストも完了させます。
  3. Buddysteel、Enderling、Luminisへ進みます。FTB Questsの達成と、Buddycards自身の進捗・装備完成率は別の仕組みです。

足りないキラカードを選んで交換

Coin Shopの「Diamond Coin → Any Foil Buddycard」ではDiamond Coinを1枚納品し、報酬表からキラカードを選びます。コインは消費されます。グミのキラ版も報酬表に含まれます。

RAD2 1.17では、この交換の納品・繰り返し設定が修正されています。以前の版から更新したワールドで挙動が違う場合は、サーバーを含めてクエストデータが1.17に更新されているか確認してください。

出典：RAD2 1.17変更履歴と配布ZIP（overrides/config/ftbquests/quests/chapters/shop.snbt）。Card Collector定義・選択報酬表は配布ZIPと同一内容を確認済み。

02 · PACKS & SETS

パックはどこで手に入る？

まずは3つの基本セットを集めましょう。各セットは27絵柄で、それぞれに通常版とキラ版（Foil / Shiny）があります。基本パック1個から出るのは通常3枚＋キラ1枚です。

セット主な入手先補足
Base Setオーバーワールド廃坑、村、ダンジョン、難破船、埋もれた宝、砂漠の寺院などのチェスト同梱設定：子どものゾンビ・村人は20%、子どもの村人ゾンビは40%。
Nether Setネザーネザー要塞、砦の遺跡、荒廃したポータルなどのチェスト。ピグリンとの物々交換同梱設定：子どものピグリン・ゾンビピグリンは20%。
End Setジ・エンドエンダードラゴン討伐、エンドシティのチェスト同梱設定：シュルカーは5%。ドラゴンはドロップ判定100%、個数上限4。

出典：ゲーム内ガイド Base / Nether / End

RAD2独自のDungeon Crawl戦利品にもBase Packが登録されています。ただし、追加構造物のすべてのチェストに入っているわけではありません。

上表の確率はRAD2クライアント配布ZIP内の設定値です。専用サーバーの設定・既存ワールドの変更がある場合、実際の値は異なり得ます。

出典：RAD2 1.17公式配布ファイル内の overrides/config/buddycards-client.toml、overrides/config/paxi/datapacks/radrecipes/data/dungeoncrawl/loot_tables/chests/stage_1.json。以下のRAD2固有の値は配布時の設定を示します。

レア度とカード番号

レア度はカードの四隅で判別できます。キラかどうか、鑑定の等級が何か、とは別の分類です。

レア度27枚セットの番号四隅の特徴1枚ごとの抽選率
Common1〜12色付きの角なし50%
Uncommon13〜21黄色2か所30%
Rare22〜25青色4か所15%
Epic26〜27黄色2か所＋紫色2か所5%

数値はレア度全体の確率です。特定のカード1種類の排出率ではありません。通常枠とキラ枠で同じレア度抽選を行います。

Mystery Pack

複数のセットからカードを引ける特別なパックで、9枚中2枚がキラです。RAD2同梱設定では読み込まれたセットだけを抽選対象にします（boringMysteryPacks = true）。未導入のCreateセットを補完するためのパックではありません。

出典：パックの抽選処理 / Mystery Pack

03 · STORAGE

集めたカードをしまう・飾る

アイテム用途・容量使い分け

04 · COLLECTION REWARDS

セットを完成させてメダルを手に入れる

セット完成の進捗報酬としてメダルを獲得できます。Curiosの対応スロットに装備すると、セットごとの効果を得られます。持ち物に入れているだけでは装備効果は発動しません。

2.5.3では、通常・キラ両方をそろえる必要はありません

基本セットの進捗データは27種類のカードIDを判定し、キラや鑑定の状態は指定していません。各絵柄を通常版またはキラ版のどちらかで取得すれば条件を満たします。ゲーム内ガイドの「通常とキラをすべて」という記載より、実際の進捗データを優先しています。

メダル通常の効果Buddy Boost IBuddy Boost II
Base移動速度上昇 I移動速度上昇 II移動速度上昇 III
Nether火炎耐性炎上中に移動速度上昇 Iを追加炎上中に移動速度上昇 I・攻撃力上昇 Iを追加
End耐性 I浮遊を定期的に解除耐性 II＋浮遊を定期的に解除

セット完成の判定はインベントリの変化で記録されます。収納の中にあるカードを集めても進捗が埋まらないときは、一度プレイヤーのインベントリへ移してください。

05 · BUDDYSTEEL

コレクションで育つ装備

Buddysteelは、カードを素材にした金属です。剣・道具・防具などを作れます。余ったカードを使い、収集の進み具合に応じて装備を強くしていきます。

基本の作り方 · 不定形レシピ

鉄ブロック ×1 ＋ ラピスラズリブロック ×1 ＋ カード ×3

→ Buddysteel Blend ×1 → 精錬 → Buddysteel Ingot ×1

通常のかまどでは精錬に1,600 tick（20 TPSなら80秒）かかります。少量の鉄インゴットやラピスではなく、ブロックを使うレシピです。RAD2 1.17の配布スクリプトには、この基本レシピの個別変更は見つかりませんでした。実際の材料表示はRAD2内のJEIでも確認してください。

RAD2のPMMO装備条件

対象通常BuddysteelPerfect Buddysteel
防具4部位（着用）Endurance 10Endurance 48
ツルハシ・斧・シャベル・クワ（道具使用）Gathering 18Gathering 35

Luminis PickaxeはGathering 33。上表は対象を指定した同梱設定で、剣やほかの装備に同じ数値を当てはめるものではありません。使えない場合はゲーム内ツールチップも確認してください。

RAD2独自の追加属性

通常Buddysteelの防具各部位・対象道具にはSerendipity +0.25、Perfect系には+0.5の設定があります。対象の通常剣・道具にはLife Steal +0.02、Perfect系には+0.05を付与。Perfect防具は各部位にMagic Damage Multiplier +0.2も設定されています。これらは収集率による強化とは別枠です。

数値はスクリプトで加算される属性値です。ほかの装備・効果を含む最終ダメージや、すべての攻撃での回復量を保証するものではありません。

出典：RAD2 1.17公式配布ファイル内の overrides/config/pmmo/req_wear.json・req_tool.json、overrides/scripts/item_attributes.zs。以下のRAD2固有の値は配布時の設定を示します。

完成率の仕組み

2.5.3の装備が参照するのは、読み込まれているカードのうち、一度でも拾ったことがある種類の割合です。枚数の合計でも、バインダーに入っている枚数でもありません。同じ絵柄のキラや鑑定違いを増やしても、別のカードIDとしては数えません。RAD2では基本3セット81種類＋BYG 27種類＋Aquaculture 18種類＋Farmer’s Delight 18種類＋グミ6種類＝150種類が計算上の対象です。

  1. 未収集の種類を入手します。チェストなどから移しただけで反映しない場合、安全な場所でカードを落として拾い直します。
  2. 強化したいBuddysteel装備を手に持ち、右クリックして記録を更新します。
  3. ツールチップの完成率を確認します。連携MODで対象カードの種類数が増えると、分母も変わります。
完成率が96%で止まったら、グミ6種類も確認

144絵柄だけを収集した場合は144÷150＝96%。Farmer’s Delightのパックに入る食用カードも強化対象ですが、メダル取得には不要です。グミを食べる前に拾得を記録しましょう。

Perfect Buddysteel

LuminisとZylexを使う上位素材です。Perfect Buddysteel Ingotと通常のBuddysteel装備を鍛冶台で組み合わせ、上位装備に更新します。収集率で成長する性質は引き継がれます。RAD2のクエスト説明には「キラカードで強化」とありますが、指定JARの完成率計算は通常・Perfectで共通で、キラの状態を判定していません。このWikiでは実装側を採用し、キラ収集は追加のコレクション目標として扱います。

出典：基本レシピ / 精錬 / 完成率の計算 / 更新操作 / 上位装備

06 · GRADING

鑑定は、さらに集めたい人のために

未鑑定のカードをメインハンド、Grading Sleeveをオフハンドに持って使用すると、スリーブを1個消費してカード1枚を鑑定します。等級はD・C・B・A・Sの5段階。2.5.3では鑑定済みのカードを同じ操作で再鑑定できません。

等級DCBAS
補正なしの確率39.8%32%18%10%0.2%

実装の1〜500の乱数と境界条件から算出。Grading Luckなどの補正がある場合は、この表の確率とは異なります。鑑定の等級は、装備の完成率を直接増やすものではありません。

キラをそろえたい場合は、鑑定とは別にCoin Shopの選択交換も利用できます。キラの有無とD〜Sの等級は別の属性です。

スリーブのレシピ

作業台の上段を「金インゴット・板ガラス・鉄インゴット」、中段を「鉄インゴット・板ガラス・金インゴット」と並べると、Grading Sleeveが2個できます。

出典：鑑定処理・確率 / スリーブのレシピ

07 · LATE GAME

LuminisとEnderling

MINING

Luminis / Deep Luminis

地下の低い場所で見つかるLuminis鉱石から結晶を集め、精錬して素材にします。光る建材やPerfect Buddysteelの材料になります。

Deep Luminisは希少な派生素材。鉱石からの入手に加え、2.5.3では通常のLuminisブロックを爆破して得る方法もあります。入手しやすさは専用装備などで変わります。

TRADING

Enderling / Zylex

Enderlingはエンダーマンとともにまれに現れる友好的な存在です。カードと、独自の素材・通貨であるZylexを取引します。

取引を使い切ったらZylex Tokenで更新できます。同じ個体と取引を重ねると、Zylex系の特別な装備を扱うようになります。Zylexも上位Buddysteelの材料です。

出典：Luminis / Deep Luminis / Enderling / Token / 特別な取引

08 · MOD INTEGRATIONS

RAD2に収録されている追加セット

RAD2 1.17にはBYG・Aquaculture・Farmer’s Delightが収録されています。追加インストールなしで次の3セットを集められます。基本3セットと合わせて6セットです。

連携セット絵柄数 / パック集め方メダルの基本効果
Oh The Biomes You'll Go（BYG）27種類 / 4枚各ディメンションのBYG素材などを使ってパックを作成。跳躍力上昇 I
Aquaculture18種類 / 3枚Buddycard Hookを付けた釣り竿やBuddysteel Fishing Rodで釣る。水中呼吸
Farmer’s Delight18種類 / 3枚＋グミ作物からBuddybeansなどを集め、カード片と料理してパックにする。Nourished I

18枚セットもパックにはキラ1枚が含まれます。番号はCommonが1〜7、Uncommonが8〜13、Rareが14〜16、Epicが17〜18です。

Createの製造工程はRAD2標準構成の対象外

Create本体は収録されていないため、一般的なBuddycardsガイドにあるCreate Packの工場づくりは不要です。RAD2はCreateメダルもJEIから隠しています。

出典：RAD2 1.17のmodlist.html・manifest.json・クライアントスクリプト。各セットの基本仕様はBuddycards同梱ガイドを参照。

09 · TROUBLESHOOTING

よくある疑問

展示棚がJEIに出ない・作れない

RAD2 1.17では木製Card Displayのレシピを削除し、JEIでも非表示にしています。故障とは限りません。カード保管にはBinderやVaultを使ってください。

完成率を上げたのに装備が使えない

PMMOのスキル条件は完成率と独立しています。通常防具はEndurance 10、Perfect防具は48。ツルハシなどはGathering 18／35を確認してください。

メダルは取れたのに、装備の完成率が低いのはなぜ？

別々の判定を使っています。メダルはインベントリに入った種類、装備は拾った統計を参照します。安全な場所でカードを拾い直してから、装備を手に持って右クリックしてください。連携セットが完成率の対象になっている場合もあります。

キラカードやSランクは、攻略に必須？

2.5.3の基本セットのメダル条件には、キラや鑑定ランクの指定はありません。まずは各絵柄を集め、キラや鑑定は追加の収集目標にすると進めやすくなります。

同じカードが余ったらどうする？

バインダーやBuddysteelの素材に使えます。RAD2にはFarmer’s Delightがあるため、まな板とナイフでカード片への加工にも使えます。収集用の1枚を確保してから素材にするのがおすすめです。

メダルを持っているのに効果が出ない

RAD2にはCuriosが収録されています。対応するメダルスロットに装備しているかを確認してください。通常のインベントリに置くだけでは効果を使えません。

手元のレシピがこのページと違う

このページはRAD2 1.17の公式クライアント配布ZIPが基準です。RAD2のバージョン、追加MOD、サーバー独自変更、古い設定の残存を確認し、JEIの表示と照合してください。Minecraft 1.17向けのページではありません。
